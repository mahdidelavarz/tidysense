# New Frontend Page

1. Confirm the page exists in accepted IA/flow and check `CON-001/CON-002`.
2. Resolve router/folder decisions before creating the first real page.
3. Define purpose, user questions, hierarchy, actions, entry/exit points, states, edge cases, product rules, AI involvement, and UX risks.
4. Define route/search params and access boundary.
5. Reuse API service/query hooks and design-system primitives.
6. Implement feature components and entity-specific forms.
7. Cover the UI state matrix, Persian/RTL, responsive, keyboard/focus, and screen-reader behavior.
8. Test critical interactions and integrate into navigation without duplicating route state.

Do not make page components own transport or canonical business logic.
